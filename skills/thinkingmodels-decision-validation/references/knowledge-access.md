# 可选：补充 ThinkingModels 公共知识

本技能不依赖联网、MCP 或账号。已有材料足够时直接完成任务。

若用户环境已经配置 ThinkingModels 公共 MCP（`https://thinkingmodels.site/mcp`），且具体模型知识有助于当前问题，可使用其只读公共工具：`get_taxonomy`、`search_models`、`get_model`、`get_model_lineage`、`get_model_sources`。先按问题查找，再读取相关模型；只在需要理解关系或核对来源时继续查谱系与来源。

这只是可选访问说明，不是安装或配置授权。不要自动修改 MCP 配置、申请权限，或把用户的私密材料发送给公共服务；检索词使用不含敏感信息的通用概念。

只引用实际返回且已读取的内容与链接，保留返回的来源信息。服务不可用或未检索时明确写“未检索”；若使用自身常识作解释，标为一般知识，不伪造站点引文。工具名称或参数若与环境提供的定义不同，以实际工具定义为准。
